# Dummy Testing App

A local Power Apps Code Apps feature playground built with React, TypeScript, and Vite. It demonstrates responsive UI, client-side state, basic form validation, system-theme support, and a session activity feed using sample data only.

## Run locally

```powershell
npm install
npm run dev
```

Open the localhost URL printed by Vite. Use `Ctrl+C` in the terminal to stop the development server.

## Verify

```powershell
npm run build
npm run lint
```

This demo does not connect to a Power Platform environment or use a backend. All sample interactions are kept in app memory and reset when the page is refreshed.
